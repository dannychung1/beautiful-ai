Accent palette usage

Professional x AI

A color story for how we work

We pair these two colors across marketing, brand, and product. Azul represents the professional leading the work with their input and their story while Rose stands for the AI that helps them build it. We show the two together when the point is that a professional and the AI made the work jointly.

Extended palette usage

We use the extended ramps to tell data apart in charts and diagrams.

Neutral palette

We derive our neutrals from Base Blue and Gallery Grey and use them for secondary text and for the lines and surfaces inside our product.

Neutral palette usage

We use neutrals where pros need structure on a slide without adding color.

Neutral palette misuses

We keep light neutrals out of body text because they fail contrast.

Quarterly results
✕Don't set Light neutral type on Gallery Grey. It reaches only 2.2:1.
Quarterly results
✕Don't set body text in Neutral on Gallery Grey. It reaches only 3.5:1.
Quarterly results
✕Don't set Dark neutral type on Base Blue. It reaches only 2.5:1.

Misuses

Each of these breaks a contrast or ratio rule on this page.

Get started
✕Don't set white type on Agency Azul. It reaches only 2.2:1.
Needs review
✕Don't set white type on Alert Amber. It reaches only 2.3:1.
Drafted with AI
✕Don't set body text in Ready Rose on Base Blue. At 3.4:1 it passes for large type only.
✕Don't fill a slide with accents. We keep each accent to about 10% of a page.
Big news
✕Don't reach for the extended ramps to add energy. We use them to tell data apart.
You × AI
✕Don't set Agency Azul on Ready Rose. We show the pair side by side, never one on the other.
