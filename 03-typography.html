Headlines and headers

Set every headline and header in Medium. Reserve Bold for a single word or figure that stands alone as a visual element.

We set display type at 120px and up for covers, chapter openers and statement pages, and every header from H1 to H6 uses the same settings. Nothing goes tighter than 100% leading, because below that a descender lands on the line beneath it. Cap height is 0.70em and the descender is 0.213em.

Optical alignment

Left-align display type to the ink, not the text box. Pull each line left by its own glyph side bearing — roughly 0.08em for B, 0.05em for G — so the stems land on the grid.

Bold 7001 word or figure per view

Use Bold when a word or number works as a graphic, such as a hero stat or a campaign mark. Never set a full headline, a header or body copy in Bold, and never pair 2 Bold elements in the same view.

Paragraphs, labels and eyebrows

Set paragraphs, labels and eyebrows in Book, and track labels and eyebrows open to 0.12em in uppercase.

In context

Here is how the weights, sizes and tracking work together on a real page.

Typography

Layout

We build the guide, our site and every asset for professionals on 1 grid of 12 columns with 24px gutters. At 1440px the content spans 84% of the screen, so a slide story, a web page and a printed sheet share the same proportions.

Content column

Every page uses the same 12 columns. Only the width where the content stops growing changes.

Margin1/12 of the screen

At 1440px the margin is 120px. Use the same ratio for any frame, so a 1920px asset gets 160px.

Marketing pagesStop at 1200px

Our site holds its content at 1200px above 1440px, so professionals read product copy at a comfortable measure.

Showcase pagesGrow to 2280px

Campaign pages, guides and galleries keep 84% of the screen up to 2280px, so imagery and specimens fill large displays for teams and leaders.

Spans

Span every element across whole columns, and keep body copy between 45 and 70 characters a line.
